# 新 TCP 参数空间检查

两臂 TCP 均为 `[0, 0, 172, 0, 0, 0]`。参考点是当前 ZED 图像的眼药水瓶嘴
像素 `(627, 498)`，深度约 648.88 mm，邻域有效率 80%，深度极差 6.71 mm。
只做控制器查询和 `only_check_type > 0` 路径检查，未执行运动、未修改控制器配置。

## 范围和结果

- 每臂 63 个位置样本：相对瓶嘴 XY 各取 -20、0、20 mm，Z 取上方
  0、5、10、20、30、50、100 mm，保持当前朝向。
- 每臂 27 个姿态样本：在瓶嘴正上方 20、50、100 mm，pitch 相对当前取
  -10、0、10°，yaw 取 -15、0、15°，roll 不变。
- 共 180 个端点样本，16 次初始往返路径检查，14 次有针对性的复查。

| 检查 | 右臂 | 左臂 |
|---|---:|---:|
| 位置端点通过 | 50/63 | 60/63 |
| 姿态端点通过 | 27/27 | 27/27 |
| 上方 ≥20 mm 的位置样本 | 36/36 | 36/36 |
| 瓶嘴正上方 0 mm | 不通过 | 通过 |
| 瓶嘴正上方 5–100 mm | 6/6 | 6/6 |

端点通过仅指 `is_tcp_limit=False`，不是完整路径、连续空间或碰撞安全证明。

## 往返路径参数

参数为“空中速度/加速度；起始抬升与近目标速度/加速度”，单位 mm/s、mm/s²。
往返检查使用同一套直线路径和当前关节起点，包含返回原位的路径。

| 组合 | 参数 | 右臂上方20 mm | 左臂上方20 mm |
|---|---|---:|---:|
| slow | 5/5；0.5/0.2 | 1/1 | 2/3 |
| moderate | 15/10；2/1 | 1/3 | 1/1 |
| normal | 30/20；5/5 | 1/3 | 3/3 |
| fast_candidate | 50/50；10/10 | 3/3 | 1/1 |

上方 50 mm 的右臂 slow、moderate 均为 0/3；右臂 normal、fast_candidate
各初检 1/1。左臂上方 50 mm 四组均初检 1/1，未重复验证。

失败包括 detail=24（速度超限）和 detail=255（原因尚未确定）。右臂部分方案
初检通过、复查失败；左臂 slow 初检失败、复查通过。不能由此推断更快更安全，
也不能自动忽略 255。左臂 normal、右臂 fast_candidate 的三次通过均只是预检，
尚未按新 TCP 和该目标做实物运动验证。右臂不据此直接升级默认速度。

## 结论和后续

新 TCP 下，两臂瓶嘴上方 20 mm 的局部端点样本具备可达性，原先部分低位限制改善。
但右臂完整路径检查存在参数相关、不一致的拒绝结果，因此本次保持两臂不动。
应先进一步定位右臂 detail=255 和具体失败路径段，再决定实际执行参数。
若需要实物验证，必须从当时实际关节姿态重新检查，并逐臂执行、检查对齐和退路。

此结果没有完成独立的双臂物理坐标精度验证，未测试两臂同时运动，也未检测外部碰撞。
相机深度误差、夹爪中心定义和控制器预检误差均未被这些数字消除。
