Simple只能抓四个边角（两个下摆角和两个袖口）。仅当要展开的对应衣角或袖口被其他布层覆盖、不可见时使用几何 Skill；对应边角可见时用 Simple。一次未揭开且该边角仍被覆盖时可继续使用 Skill；不能仅因大块内收、褶皱、歪斜或角点难辨触发。
- 输入：在该部位附近的可见外轮廓选定位点 Q，返回 boundary_point_px=Q、chord_endpoints_px=[]。不为得到预设抓点反复挑选 Q。不要猜隐藏角坐标。附 region_name、evidence 和期望水平拉距 pull_distance_mm（正数、毫米，不设固定上下限；须满足工作边界和完整路径检查）。
- 程序：返回 skill="garment-tangent-grasp"，grasp_px/target_px=null；宿主调用现有 measured_candidate → contour_normal_grasp.geometry。CV 计算内法线、正向最远交点和向外抓放点，模型不重算。
- 空间不足：原定对向拉动会出界时，可先用 make-space-for-skill 反方向抓放留出空间；同一 round 中重新拍照后，再按新轮廓规划正向揭开。两段分别检查，第一段失败不继续；第二段不再追加腾空间动作。
- 结果：候选沿既有深度、分区、运动检查执行；无法生成时使用宿主现有失败或重选流程。

## 完整局部切线算法

1. 观察当前图并对照目标图，确认要展开的对应衣角或袖口被布层覆盖、不可见；选择该部位附近的可见衣物边界。
2. 用 CV 分割衣物并提取轮廓，在目标边界上选点 C，用其附近的轮廓拟合单位切向量 t。
3. 计算法线 n = ±(−t_y, t_x)，选择从 C 穿入衣物的一侧。
4. 从 C 沿 n 穿过衣物，枚举所有正向轮廓交点，统一选距离 C 最远的交点 E；多个交点或中途经过凹口、孔洞本身不构成拒绝原因。
5. 将交点向衣物内部偏移 δ，得到抓点 G = E − δn；抓起后沿 +n 继续向外拉，尝试带动目标区域展开。
6. 动作后重新观察，再规划下一次抓取。

C 是用于拟合切线的定位边界点，不是最终抓点。最终抓点来自对侧最远交点 E；拉动方向是法线 +n，不是切线 t，也不是从 C 直接向外拉。

输出目标边界、C、切线、法线、抓点 G 和拉动箭头，并给出抓点坐标与单位方向 n。当前接口由模型输出定位点 Q（boundary_point_px），CV 吸附到轮廓得到 C，计算并保存其余几何量。

若局部边界弯曲或遮挡导致方向不稳定，或最终交点落到画面截断处、实际抓点中心不属于可见布料，标为无效或待复核。单张 RGB 的折叠判断是推测，几何可行不代表一定能展开。
