# 割线（弦线）法

## 使用条件

仅当当前图中看不到要展开的对应衣角时使用；结合当前图与目标图说明该衣角不可见的依据，在其邻近可见轮廓选边界。不猜隐藏衣角的像素坐标。对应衣角已经可见时，不使用本方法继续拉动；皱纹、歪斜或边缘可抓本身不构成使用条件。已达到目标展开形态则结束；没有适用的不可见衣角或可靠邻近边界则报告无适用动作。

1. 观察原图，确认对应衣角不可见后，选择该衣角附近的区域，确定与其相关的完整可见边界段。
2. 用 CV 分割衣物并提取轮廓，在同一目标边界段的两端选 A、B，以弦线 AB 表示整体方向；不能为了得到期望抓点反向选择端点。
3. 计算单位方向 u = (B − A) / ||B − A||，取所选边界段的弧长中点 C，而非弦线中点。
4. 计算法线 n = ±(−u_y, u_x)，选择从 C 穿入衣物的一侧。
5. 从 C 沿 n 穿过衣物，枚举所有正向轮廓交点，统一选距离 C 最远的交点 E；多个交点或中途经过凹口、孔洞本身不构成拒绝原因。
6. 将交点向衣物内部偏移 δ，得到抓点 G = E − δn；抓起后沿 +n 继续向外拉，尝试带动目标区域展开。
7. 动作后重新观察，再规划下一次抓取。

输出目标边界、A/B/C、弦线 AB、法线、抓点 G 和拉动箭头，并给出抓点坐标与单位方向 n。

弦线不等于物理折痕。若目标边界跨越多个折叠、被遮挡，或最终交点落到画面截断处、实际抓点中心不属于可见布料，标为无效或待复核。单张 RGB 的折叠判断是推测，几何可行不代表一定能展开。

选点建议：选择清楚、较平滑的轮廓，弦线端点尽量分开，法线尽量穿过较宽布片，向外放置尽量留出桌面余量。这些建议不作为最小像素间距或跨度的硬门槛。若方向或有效抓放点确实无法计算，将具体失败原因反馈给规划器重新选边界；当前 unfold 最多追加两次选点。实测深度、设备运动约束仍由原执行链检查。

当前双 Arm7 planning 分工：Host 使用独立 CV 分割生成整件衣物掩膜和轮廓，不接受模型描绘的多边形或背景点。Codex 只选择 skill 并给定位点 Q；弦线法另给 A/B 两端。切线、弧中点、法线、最远交点及最终抓放点均由 CV 计算。当前自动分割针对浅色衣物／黄色垫板，不宣称适用于任意配色。
