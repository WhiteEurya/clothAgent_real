# RealSense 实时调参

在项目目录执行：

```bash
conda activate cali
python scripts/tune_realsense.py
```

手动打开终端显示的网址，默认 <http://127.0.0.1:8086>。不会自动弹出浏览器。
程序只打开 RGB 相机，不连接机器人。先退出占用同一相机的折叠流程或采集窗口。

默认从 `config/perception.free_exploration.json` 选择 Cam A，并使用其中的分辨率、帧率、曝光和白平衡。实时画面显示在中央，参数位于侧栏。可用滚轮放大画面；点“恢复画面视角”回到正视图。

- 曝光、增益、白平衡、亮度、对比度、饱和度、锐度等可用滑块调整；范围与步长从相机 SDK 读取。
- 自动曝光、自动白平衡用开关调整；防闪烁等枚举参数用下拉框调整。
- 手动改曝光或增益时自动关闭自动曝光；手动改白平衡时自动关闭自动白平衡。
- “其他 RGB 参数”显示该传感器其余可写选项。“相机实际读数 / 诊断”包含只读选项和读取错误。深度 / 红外传感器参数不在这个 RGB 调参界面中。
- 滑块会同步相机实际读回值；若某选项在开流时不可修改，界面会显示 SDK 错误。
- “保存完整参数预设”保存当前相机的可写参数；“截图 + 参数”另存原始分辨率 PNG。每次用时间戳创建新文件，默认目录为 `runs/camera_tuning/`。
- “恢复本次启动参数”撤销本次界面操作，恢复启动时应用配置或预设后的参数。
- “停止相机并退出”或终端 `Ctrl+C` 释放相机；仅关闭浏览器标签页不会停止后台采集。

加载保存的完整预设：

```bash
python scripts/tune_realsense.py --preset runs/camera_tuning/你的参数文件.json
```

预设必须匹配相机序列号和传感器，避免把另一台相机的设置误用到 Cam A。预设完整验证后才写入设备；硬件写入若中途失败会显示错误，已写入项可能已经生效。

要让下一次折叠使用调好的曝光、白平衡，关闭两项自动控制后，点“写入折叠配置：曝光 / 白平衡”。这个按钮只更新所选感知配置中当前相机的 `color_exposure` 和 `color_white_balance`，并在同目录留下带时间戳的 `.bak` 备份。**其他参数目前只保存在预设中，不会自动加载进折叠流程。** 设备断电或其他采集程序重新配置后，不应假设调参值仍然保留。

其他相机或自定义流：

```bash
python scripts/tune_realsense.py --list
python scripts/tune_realsense.py --serial 你的相机序列号
python scripts/tune_realsense.py --camera A --width 1280 --height 720 --fps 30
```

远程访问时使用 `--host 0.0.0.0 --port 8086`，然后在浏览器访问相机主机的 IP。此界面没有登录功能，只在可信局域网开放。浏览器画面默认刷新 10 FPS，可用 `--preview-fps` 修改；相机自身帧率由 `--fps` 控制。
